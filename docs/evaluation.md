# FounderPath AI: Evaluation Framework

This document outlines the evaluation metrics used to measure the precision and efficacy of the FounderPath AI platform during the BCT 3.0 Hackathon.

## Track 1: User Modeling (SkillThinker™)

| Metric | Target | Measurement Method |
| :--- | :--- | :--- |
| **Skill Extraction Precision** | > 85% | Comparison of user "Raw Input" vs AI-extracted "Core Competencies". |
| **Informal Skill Coverage** | > 70% | Detection of non-certified experience (housekeeping, local trade, etc.) |
| **Discovery Loop Efficacy** | < 2 Loops | Number of follow-up questions needed to reach "Audit Ready" state. |
| **Tone Alignment** | Professional | Qualitative review of AI-generated follow-up questions for empathy and clarity. |

## Track 2: Recommendation Engine (AutoThinker™)

| Metric | Target | Measurement Method |
| :--- | :--- | :--- |
| **Skill-to-Venture Fit** | High | Manual audit of how well the "Venture Model" utilizes "Core Competencies". |
| **Financial Calibration** | ±10% | AI-generated Naira (₦) estimates vs actual local market averages. |
| **Launch-Readiness** | Day 10 | Proportion of roadmap steps that are "Immediately Actionable" without external capital. |
| **Recommendation Diversity** | High | Variety of models suggested across different personas (Tailor vs Developer vs Chef). |

## Behavioral Metrics (Nudge Center)

- **Input Conversion**: Time from "Get Started" to "Venture Generated".
- **WhatsApp Activation**: Proportion of users who provide a valid phone number for the launch sequence.
- **Blueprint Downloads**: Rate of PDF generation indicating user intent to share/present.
