# FounderPath AI: Agentic Economic GPS

FounderPath AI is a production-grade platform designed to bridge the gap between vocational skills and business ownership. By combining high-reasoning AI (Gemini 3 Flash) with localized market data, the platform turns individual human capital into launch-ready micro-ventures.

## 🚀 Core Engine Architecture

### 1. SkillThinker™ Audit
The entry point of the platform. It uses a recursive reasoning pattern to analyze user-stated competencies. If an input is too vague, the engine initiates a 3-question "Discovery Loop" to extract the nuances required for a professional business plan.

### 2. AutoThinker™ Venture Architect
Matches the audited SkillProfile against a library of viable, low-friction business models optimized for the African economic context (e.g., Nigerian localized markets). It generates:
- **Professional Business Plans**: Detailed Executive Summaries, Market Analysis (TAM/SAM/SOM), and Risk Management.
- **10-Day Operational Roadmaps**: Day-by-day tactical execution steps.
- **Unit Economics**: Itemized startup budgets (₦) and 30-day revenue projections.
- **Investor-Ready Pitch Decks**: 7-slide architectural outlines.

### 3. Market Scout™
Platform-specific tactical search queries and networking scripts for LinkedIn, Facebook Groups, and Quora, designed to help the founder find their first 5 high-intent clients.

## 🛠 Technical Stack

- **Frontend**: React 18+ (Vite) / Tailwind CSS / Framer Motion
- **AI Brain**: Gemini 3 Flash Preview (via `@google/genai`)
- **Backend/Identity**: Firebase Auth (Google) & Firestore
- **Security**: Hardened "Fortress" Rules (Attribute-Based Access Control)
- **Document Generation**: Structured Blob-to-File serialization for professional downloads.

## 🔒 Security & Data Integrity

The application implements "The Eight Pillars" of Firestore security:
1. **Identity Integrity**: Strict ownership verification for all Prosperity Profiles.
2. **Schema Hardening**: Recursive validation of all AI-generated numeric fields.
3. **Circular Protection**: Custom `safeStringify` utility to prevent runtime crashes during complex logging.
4. **Verified Access**: Mandates verified Google accounts for write operations.

## 🌍 Economic Vision

FounderPath AI targets the "Vocational-to-Entrepreneurial" friction point. It empowers individuals with practical skills (Catering, Tailoring, Digital Skills, etc.) to view themselves as Venture Founders, providing the high-level strategic planning usually reserved for elite consulting firms.
